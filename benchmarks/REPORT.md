# 性能概要

[API 別の全結果](results/unit.md) / [利用場面別の全結果](results/scenario.md) / [測定条件](METHOD.md) / [実行環境](results/environment.md)。  
時間・割り当て量は中央値で、倍率は対象 / 対照（1 を超えると対象が遅い）。  

| 処理（対照 → 対象） | 時間 ns/op（対照 → 対象） | 倍率 | 割り当て B/op（対照 → 対象） |
| --- | --- | --- | --- |
| Pipeline<br>Seq / N=4096 / 段数=2 / 全件<br>Loop → Pipeline | 13,636 → 26,611.5 | 1.952× | 177,391 → 177,688 |
| Channel<br>N=4096 / 入力容量=64<br>Direct → FromChannel | 113,467.5 → 190,152 | 1.676× | 178,232 → 178,440 |
| Channel<br>N=4096 / 入力容量=0<br>Seq → ToChannel | 15,882 → 337,950 | 21.279× | 177,432 → 177,800 |
| Cache<br>Seq / N=4096 / 負荷=0 / 利用回数=1 / 保存費用込み Reuse<br>Uncached → Cached | 11,050.5 → 23,708.5 | 2.145× | 152 → 128,488 |
| Cache<br>Seq2 / N=4096 / 負荷=32 / 利用回数=16 / 保存費用込み Reuse<br>Uncached → Cached | 1,238,657 → 171,450 | 0.138× | 752 → 260,152 |

軽い変換では、パイプライン接続や channel 変換の追加費用が目立つ。  
キャッシュは初回保存の費用と保持メモリを要するが、重い上流を繰り返し使うと再評価を省ける。  
この整数処理での結果を、外部 I/O や他の型の速度保証には使わない。
