# ADR-0003: 正式版の版番号を変更内容から決める

- 決定日: 2026-10-23
- 状態: 採用
- 日付の根拠: [Issue #66](https://github.com/meian/go-seqpipeline/issues/66) の完了日

## 背景

`v0.1.0` の後に変更内容から次の版番号を選ぶ基準が、リポジトリ内にまとまっていなかった。  
この ADR は、完了済みの Issue #66 と [版番号決定ルール](../ai/release.md) から判断を遡って記録する。  

## 決定

正式版の版番号は Semantic Versioning 2.0.0 を基に、前回の正式版からの変更内容をまとめて判定する。  
`v0.x` では互換性を壊す変更を minor とし、最低 Go バージョンの変更も公開 API の互換性とは別に判定する。  
詳細な判定基準は [版番号決定ルール](../ai/release.md) に置く。  

## 理由

同じ種類の変更に一貫した版番号を選べる。  
`v0.x` と Go 要件の変更について、リリースごとの判断の揺れを減らせる。  

## 採用しなかった選択肢

既存の判断を記録するにあたり、次の運用と比較した。  

- 版番号をリリースごとに個別判断する案: 判断基準を後から確認できない

## 影響

版番号とリリースノートの掲載基準は [版番号決定ルール](../ai/release.md) に従う。  
この ADR は決定の理由を記録し、詳細なルールを複製しない。
