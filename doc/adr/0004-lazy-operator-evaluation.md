# ADR-0004: 組み込みオペレーターの入力評価を反復時に始める

- 決定日: 2026-10-25
- 状態: 採用

## 背景

`Cache` / `Cache2` は接続時に入力を全件評価していたため、パイプラインを組み立てるだけで上流の副作用や無限入力の待機が始まっていた。  
他の組み込みオペレーターとの評価時点の違いを、今後の追加や変更でも判断できるようにする。  

## 決定

`op` の組み込みオペレーターは、変換関数の呼び出しや `Pipe` / `Pipe2` への接続時に入力を反復しない。  
返されたシーケンスの反復が始まってから入力を評価する。  
`Cache` / `Cache2` は初回反復時に全件を保存してから値を返す。  
独自オペレーターの評価時点はその実装が決める。  

## 理由

入力の実行を伴わずにパイプラインを組み立てられ、評価を始める時点を利用者が反復・収集の呼び出しで選べる。  
変換関数そのものは接続時に呼び出されるため、その呼び出しと入力の反復は区別する。  

## 採用しなかった選択肢

- `Cache` / `Cache2` の全件評価を接続時に維持する案: 接続だけで入力が実行され、他の組み込みオペレーターと評価時点が異なる

## 影響

初回反復まで入力が変わり得るため、接続時に結果を確定したい場合は明示的に収集する。  
具体的な使用方法は [利用ガイド](../guide.ja.md#cache-による評価結果の再利用)、個別の境界条件は GoDoc に置く。  
`seq.ToChannel` のような出力変換は組み込みオペレーターではなく、この判断の対象外とする。
