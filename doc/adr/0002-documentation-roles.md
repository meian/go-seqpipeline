# ADR-0002: README を導入の入口にする

- 決定日: 2026-10-20
- 状態: 採用
- 日付の根拠: [Issue #41](https://github.com/meian/go-seqpipeline/issues/41) の完了日

## 背景

README に詳細な仕様や例を集めると、導入に必要な情報が探しにくくなる。  
この ADR は、完了済みの Issue #41 と現在の文書構成から判断を遡って記録する。  

## 決定

README は概要、導入、短い基本例、詳細への参照先に絞る。  
利用上の注意は日英の利用ガイド、個別 API の契約は GoDoc、実行可能な例は Go Example、性能の測定結果は既存の性能レポートに置く。  
文書の更新運用は `doc/ai/` に置く。  

## 理由

利用者は README から使い始め、必要な詳細へ進める。  
説明の重複と README の肥大化を抑えられる。  

## 採用しなかった選択肢

既存の判断を記録するにあたり、次の構成と比較した。  

- README に詳細と例を集約する案: 導入の入口としての見通しが悪くなる

## 影響

README と利用ガイドは日英で同期し、詳細の配置と掲載範囲は [AGENTS.md](../../AGENTS.md) と [更新運用](../ai/readme.md) に従う。  
この ADR は文書の役割を記録し、個々の掲載基準は重複して定義しない。
